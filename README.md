# Projeto Loja Virtual - Backend

API REST para gerenciamento de uma loja virtual, desenvolvida com **Spring Boot**. O sistema permite cadastro de clientes, produtos, categorias, cidades, envio de emails, autenticação JWT, entre outros.

## Funcionalidades

- Cadastro de usuários e clientes
- Autenticação e autorização com JWT
- Cadastro de produtos, cidades e categorias
- Envio de email automático ao cadastrar cliente
- Atualização e ativação de usuários
- Estruturação seguindo os princípios do DDD

## Tecnologias utilizadas

- Java 17
- Spring Boot
- Spring Security
- Spring Data JPA
- MySQL
- JWT (JSON Web Token)
- Maven
- JavaMailSender

## Como rodar o projeto localmente

1. Clone o repositório
2. Rode a aplicação na classe principal
3. Certifique de colocar as credenciais corretas do banco, se não tiver crie um
4. Ative o apache e o mysql no Xampp
5. Teste no Postman
